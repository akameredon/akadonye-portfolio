# Akadonye Chibuike Macdonald — AI Generalist

Interactive personal portfolio.

**Live:** open `index.html` in any browser (or enable GitHub Pages).

## Features

- **Cinematic stage** — Four Powers boot sequence (click or press Space to replay)
- **AI Generalist console** — type `help`, `powers`, `stack`, `owerri`, `ship`, `attack`, `clear`
- **Prompt Attack** — intercept a weak commercial video prompt and score the gaps
- **Four Powers Check** — quick self-assessment
- **Opportunity Filter** — raw list vs Owerri-first filter
- **Enterprise-style metrics** on shipped work
- **Progressive enhancement** — fully readable with JavaScript disabled

## Domain

Built for an AI Generalist focused on:
- Commercial AI video prompt systems
- One-person leverage (Build · Automate · Create · Connect)
- Local opportunity systems (Owerri / Imo)

No external dependencies. Single HTML file. System fonts only.
